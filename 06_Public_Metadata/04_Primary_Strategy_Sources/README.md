# Primary Strategy Sources — v0.6

This folder records the authoritative or author-originating specifications used in G2.

Full third-party paper binaries are not redistributed in this release. The register stores identifiers, source tier, access status and claim boundaries. Rule cards are derived from the primary records and are cross-checked against the DB report and the legacy dashboard code.

Source hierarchy:

1. author paper or author-originating specification;
2. official abstract/metadata and author-posted indexed text;
3. DB report or independent implementation only as a cross-check;
4. legacy dashboard code as historical implementation evidence, never as proof of the parent rule.
