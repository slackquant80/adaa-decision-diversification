# Rights and Privacy Guardrails - v1.0

Public reproducibility does not require redistribution of every upstream input.

**Do not redistribute:** downloaded raw Yahoo/FRED market-data files or runtime objects; raw/near-raw adjusted-price files created inside `raw_freeze*` folders; the private 2023 university-project report binary; proprietary research; third-party article PDFs; local RStudio/Python session artifacts; credentials; private author/recollection notes.

**May redistribute:** frozen research code; public data-source metadata and contracts; derived exhibit/table source data; internally generated exhibits; nonprivate validation summaries; aggregate/derived diagnostics that do not substitute for the upstream raw data.

A clean reproduction may generate raw public-market inputs locally. Those are execution inputs, not release payloads. Run the provided purge utility only after completing the reproduction if you intend to redistribute a post-run tree.
